# coupdev.com

Personal link collection website built with Preact and Vite.

## 🛠️ Tech Stack

- **Framework:** Preact + TypeScript
- **Build Tool:** Vite
- **Styling:** CSS Grid + Custom CSS
- **Icons:** Custom SVG components

## 📦 Installation

```bash
npm install
```

## 🏃‍♂️ Development

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
